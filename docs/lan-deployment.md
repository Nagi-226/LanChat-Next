# 公司局域网使用说明

2026-11-21，Windows / Qt6 初版。

## 1. 选定一台常开 PC

所有员工连接同一台主机。主机可以使用以太网、2.4 GHz 或 5 GHz Wi-Fi，只要电脑之间能互相访问。访客 Wi-Fi 的客户端隔离、跨 VLAN 策略和 Windows 防火墙可能阻止连接。

主机打开 LanChat，点击右上角 **服务器**，选择 **本机托管**，端口默认 `12346`，单附件默认 **100 MB（100 × 1024 × 1024 字节）**。

普通本机托管由客户端启动服务端；关闭这个客户端会停止它自己启动的服务端。公司长期使用建议先独立启动主机：

```powershell
cd "$env:LOCALAPPDATA\LanChat-Qt"
.\start-lan-host.ps1 -Port 12346 -MaxAttachmentMb 100 -QuotaMb 5120
```

独立主机后台运行，关闭聊天窗口不影响其他员工；PC 仍需保持开机、联网并避免睡眠。可把这条命令加入 Windows 任务计划，在主机用户登录时启动。脚本不会自动创建任务。

管理员仅在主机上放行专用网络、同一子网的端口：

```powershell
New-NetFirewallRule -DisplayName 'LanChat LAN 12346' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 12346 -Profile Private -RemoteAddress LocalSubnet
```

此命令需要管理员 PowerShell。应用不自动扩大防火墙权限。使用 `ipconfig` 查主机 IPv4，建议在路由器为主机保留固定地址。

## 2. 分发客户端

维护者完成 `scripts/deploy-qt.ps1` 后，可运行 `scripts/package-lan.ps1` 生成 Windows ZIP。包包含客户端、服务端、Qt 运行库、可选板端桥及安装脚本，排除账号、数据库和日志。

员工解压 ZIP，运行里面的 `install.ps1`；安装到当前用户 `%LOCALAPPDATA%\LanChat-Qt` 并创建桌面快捷方式，通常不需要管理员权限。启动后点击 **服务器 → 连接公司局域网主机**，填写主机 IPv4 或可解析的主机名及端口，然后 **保存并重新连接**。

远程模式不会启动本机服务端。不同服务器的账号、群和历史相互独立；切换服务器会清空当前会话视图并重新登录。

## 3. 账号、群聊和附件

- 员工自由注册用户名和密码，注册成功后返回登录。
- **建群**后会显示群名和群 ID；其他员工点击 **加入**，输入群 ID。此初版凭 ID 自由加入，没有审批或邀请口令。
- 群头部显示 ID，右栏只显示该群成员，可退出群。打开会话加载最近 50 条，**更早消息**继续读取，服务端保存历史。
- 文字和普通 Unicode 表情直接输入或粘贴，例如 `😀 👍 🎉`。专用表情选择面板留待后续。
- 点击 **附件**、拖入文件，或 `Ctrl+V` 粘贴剪贴板图片。PNG/JPEG/WebP/BMP 支持预览，GIF 支持动画；其他文件使用下载卡片。
- 接收端点击 **下载 / 预览**，下载完成可 **另存为**。图片可查看原图；文件不会自动执行。
- 显示实际上传/下载进度，可暂停、继续、取消。连接中断会暂停；重新登录后点 **继续**。未完成任务按服务器和账号保存，重启客户端后仍可继续。
- 附件由主机保存，接收者不依赖发送者的本地路径。每块最多 48 KiB，完成后服务端及下载端校验 SHA-256；不把整个文件塞入一条 JSON 帧。

## 4. 存储和维护

主机数据：`%APPDATA%\LanChat-Next\data\lanchat.db` 和同目录 `attachments\`。备份时停服务，整体复制数据库及附件目录，再启动主机；不要只备份数据库。

环境变量：`LANCHAT_ATTACHMENT_MAX_MB` 默认 `100`，`LANCHAT_ATTACHMENT_QUOTA_MB` 默认 `5120`。配额计算包含已分配的未完成上传，满额会拒绝新附件。独立主机通过 `start-lan-host.ps1` 参数设置；已运行的服务端需重启后才能应用新限制。

客户端每个服务器/账号的完整附件缓存上限约 **512 MB**，优先删除旧缓存；删缓存不删除服务端原件。未完成 `.part` 保留用于续传，取消下载会清除该部分文件。服务端未完成上传超过 7 天在下次启动时回收。已发布附件不自动删除，业务留存策略及管理界面仍在待办。

## 5. 使用边界与验收

这是可信公司局域网的初版：密码存储使用 SHA-256 预哈希后 bcrypt；消息与附件按登录身份、私聊参与者及群成员校验。服务端能读聊天和附件，当前 TCP 通道没有 TLS / 端到端加密，因此应部署在可信 LAN 或加密组网内，不能直接把该 TCP 端口映射到公网。

客户端目前是 Windows PC 应用。手机能加入 Tailscale/ZeroTier 网络，不代表手机已有 LanChat 客户端。

本机已用独立真实客户端和服务端验证，包含 Unicode、群历史、图片/GIF/文件、暂停续传、服务器重启、权限拒绝和 100 MB 边界。**实际公司网内两台物理 PC、访客隔离/防火墙及长时间多人压力仍需部署时验收**。

管理员控制注册/入群、组织权限、审计与留存策略、TLS、移动客户端、专用表情面板和生产压力测试列入后续工作。

板端仍只接收文字。图片、GIF、文件内容和附件引用由 Console 两层入口过滤，不下发 ESP32-S3。
