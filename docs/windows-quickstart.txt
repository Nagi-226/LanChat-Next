LanChat-Next 联机使用说明（Windows 10/11，64 位）
更新：2026-11-23

一、安装与连接
1. 双击包内 LanChat-Next-Setup-*.exe，按向导完成安装。
   程序装到当前用户目录，通常无需管理员权限。Qt 运行库已随包提供。
2. 从桌面或开始菜单打开 LanChat-Next。
3. 在登录页「服务器地址」填写测试发起者提供的地址，格式为 地址:12346。
4. 点击「连接」，等待注册和登录可用。完整设置登录后在左下角齿轮查看。
5. 在该主机注册自己的用户名和密码，随后登录。
6. 点击「加入」，输入测试发起者给你的群 ID，然后进入群聊。

二、两种网络
同一局域网：填写消息主机在该网络的 IPv4 地址。
不同地点：安装官方 Tailscale 客户端，取得访问消息主机的组网权限，
          由主机管理者完成设备邀请/授权；随后填写主机的 Tailscale 地址。
          官方下载：https://tailscale.com/download/windows
          组网成员权限、LanChat 注册和群 ID 分别配置。
主机需保持开机、联网。测试者共用发起者提供的同一个地址和端口。

三、建议一起测试
窗口操作：双击顶部标题栏切换最大化 / 还原；拖动标题栏到屏幕顶部松开可最大化，
最大化后可拖回普通窗口，普通窗口的边缘与四角可调整大小。吸附遵循 Windows 设置。
右上角三个图标尺寸统一，中间按钮随窗口状态显示最大化或还原图标。
发送中文、英文和普通表情（例如 😀 👍 🎉）；确认每条消息只显示一次。
发送图片、GIF 和普通文件；接收后检查预览、下载、另存为。
单附件默认上限为 100 MiB；可测试暂停、继续，以及断开网络后重新连接续传。
板端查询在专用账号私聊输入「感知 / 链路 / 设备 / 帮助」；配置群中用 /感知 等命令。
普通聊天和 PC 附件传输可在没有板子的电脑上使用。

板端详细日志：在连接板子 USB 的主机上登录，打开「左下角齿轮 → 设置 → 板端连接 → 运行日志」，
选择当前板端串口（本机通常为 COM3），点击「开始采集」。
可以筛选、暂停显示、复制和导出；暂停和清空视图不会清空查询缓存。
烧录或使用其他串口监视器前点击「停止采集」，以释放串口。
私聊专用板端账号或在已配置群中发送 /日志、/日志 错误、/日志 链路、/日志 帮助。
默认返回最近 20 条已采集日志，脱敏且限制长度；断开时明确标为历史缓存。
其他 PC 无需接板子或安装串口开发工具，可通过聊天查询；远程连续日志面板尚未接入。
日志只能记录启用采集以后实际收到的内容，采集前或断开期间的输出无法补取。

文字状态 AI：由连接板子的主机在「设置 → 板端连接 → AI 状态问答」配置并启用模型。
测试者私聊专用板端账号可自然提问；配置群用 /AI 问题；/AI 清空清除当前模型上下文。
感知、链路、设备和 /日志 仍走原只读查询。完整长回复保留在 PC 聊天区。
模型推理在外部服务完成；小智语音尚未集成。AI 调用可能产生费用。
安装包不含任何人的模型密钥；问题、状态摘要和最近几轮对话会发给配置的模型服务。

四、更新与卸载
再次安装同一版本或后续版本可更新程序文件；安装器提示关闭程序时先保存操作。
通过 Windows「已安装的应用」或开始菜单卸载。
卸载保留个人账号设置、聊天主机数据和附件缓存。
程序目录：%LOCALAPPDATA%\LanChat-Qt
主机数据：%APPDATA%\LanChat-Next\data

五、反馈测试结果
记录 Windows 版本、网络（同一局域网 / 异地 Tailscale）、使用的主机地址和端口，
