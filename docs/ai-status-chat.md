# AI 状态问答

登录后在 **左下角齿轮 → 设置 → 板端连接 → AI 状态问答** 配置模型接口，启用后点击 **保存并连接**。API 密钥由当前 Windows 用户加密保存，界面留空表示保留已保存的密钥。

点击 **在聊天中询问板端状态** 打开专用板端账号的私聊。自然提问及追问例如：

- “现在板子各项状态怎么样？”
- “疲劳结果没算出来，可能是什么原因？”
- “现在可用内存多少？这能说明内存泄漏吗？”
- “链路是否稳定？哪些数据还不足以判断？”

配置群用 `/AI 问题`，普通群聊不触发。`/AI 清空` 清除当前会话的模型上下文；感知 / 链路 / 设备 / 帮助和 `/日志` 仍使用原确定性查询。

每次提问由后台 Console 获取三类新的板端状态快照，回答带采集时间。完整 AI 回答留在 PC；开启鲸鱼娘沉浸模式后，S3 自动显示逐句字幕并播放 PC 合成的中文语音（Windows / 本机少女声线）。设备控制、语音输入和小智通用 AI 为后续。模型服务可能计费；全局最多 4 个任务，单会话最多 1 个，请等待回答后追问。

模型上下文最多三轮，仅保存在 Console 内存，10 分钟无活动过期。**聊天记录仍按 LanChat 保存**；清空上下文不会删除聊天历史。发送给模型的是问题、状态摘要和最近几轮对话，不包含图像、附件、完整串口日志或密钥。

支持切换服务商的 OpenAI 兼容渠道；商汤适配见[渠道记录](sensenova-ai.md)。2026-11-24 用户自己的 DeepSeek 官方 `deepseek-flash` 已通过模型列表、短中文生成与真实 S3 状态问答，当前 `none` 参数实测有效。普通知识可自由提问，设备事实仍以当前快照为准。角色、字幕与语音初版见[鲸鱼娘沉浸模式](whale-immersion-plan.md)。

断线、过期、未计算和未接入会明确提供给模型；AI 解释可用原关键词查询核对。接口不通时显示调用错误，普通聊天和确定性查询继续使用。

登录后 **设置 → AI 与会话** 可检测模型列表、调整输出 / 超时 / 每日调用次数 / 间隔 / 并发，查看本机次数与 token 统计、清空本人私聊上下文。默认每日 100 次，失败计入，重启保留，跨主机本地日期恢复；计数不等于实际账单。HTTP 429 区分服务商限流、额度不足和原因不明，按 Retry-After 冷却（无该头时 60 秒），不自动重试；冷却期间关键词 / 日志查询仍可用。具体边界见[设置说明](settings-roadmap.md)。

实现和验证边界：[Console 问答说明](https://github.com/Nagi-226/RoboMind_Console/blob/master/docs/ai-status-chat.md)。
