# AI 状态问答

## 保存和应用模型配置

登录后在 **左下角齿轮 → 设置 → 板端连接 → AI 状态问答** 切换 **DeepSeek / GPT / 配置 3**。旧版的在用配置会迁入 DeepSeek；迁移前已启用且信息完整的配置可恢复为迁移时的版本。

- **保存配置** 只保存当前表单。**恢复上次通过的配置** 把最近通过文字回复验证的地址、模型和密钥恢复到表单；要应用恢复的配置，再点验证。验证失败会保留原来的可用配置。
- DeepSeek 的 **验证并应用** 会验证并启用该配置；GPT 的 **验证配置** 通过后，还需在同页填写 **GPT 板端账号 ID / 密码** 并点 **保存并连接**。确认 **GPT 单聊状态** 显示在线。**配置 3** 可保存和验证，暂未绑定第三个聊天账号。
- 验证会发出一条简短模型请求，可能计费；与「AI 与会话」里的 GET 模型列表检测不同。API 密钥由当前 Windows 用户加密保存；同一协议和地址下可留空保留本组密钥。更改地址或协议时需重新填写。

## 私聊与板端显示

角色头像按账号设置的头像 ID 加载客户端本地应用数据目录中的 `avatars/6201.png` 或 `avatars/6202.png`；使用正方形 PNG（最大 512×512），没有本地图时显示默认头像。立绘和头像文件需在本机单独准备。

从联系人选择 **RoboMind-S3_DS** 或 **RoboMind-S3_GPT**；**在聊天中询问板端状态** 是打开主账号私聊的快捷入口。自然提问及追问例如：

- “现在板子各项状态怎么样？”
- “疲劳结果没算出来，可能是什么原因？”
- “现在可用内存多少？这能说明内存泄漏吗？”
- “链路是否稳定？哪些数据还不足以判断？”

当前只有配置了群 ID 的主账号支持群内 `/AI 问题`。GPT 目前仅支持私聊，两位 AI 还不能在群里互答。`/AI 清空` 清除当前会话的模型上下文；感知 / 链路 / 设备 / 帮助和 `/日志` 仍使用原确定性查询。

后台 Console 为每个问题取得感知、链路、设备三类快照。两个账号共享同一台 S3 的连接；各自的完整回答回到原私聊。双账号在线时，发出私聊文字即可在板端切到对应角色：DS 为鲸鱼娘、GPT 为白龙娘。字幕与 PC 合成的语音等待板端确认目标画面；切走后到达的回复仍在原私聊显示。设备控制、语音输入和小智通用 AI 为后续。

模型上下文最多三轮，仅保存在 Console 内存，10 分钟无活动过期。**聊天记录仍按 LanChat 保存**；清空上下文不会删除聊天历史。发送给模型的是问题、状态摘要和最近几轮对话，不包含图像、附件、完整串口日志或密钥。

本机已验证 DeepSeek 官方 `https://api.deepseek.com` / `deepseek-flash`、微链 `https://api.weelinking.com/v1` / `gpt-6.2-sol` 可使用 OpenAI 兼容接口回答板端状态。第三方可用模型以各渠道实际响应为准；商汤适配见[渠道记录](sensenova-ai.md)。角色、字幕与语音见[沉浸模式](whale-immersion-plan.md)。

断线、过期、未计算和未接入会明确提供给模型；AI 解释可用原关键词查询核对。接口不通时显示调用错误，普通聊天和确定性查询继续使用。

登录后 **设置 → AI 与会话** 可检测模型列表、调整输出 / 超时 / 每日调用次数 / 间隔 / 并发，查看本机次数与 token 统计、清空本人私聊上下文。默认每日 100 次，失败计入，重启保留，跨主机本地日期恢复；计数不等于实际账单。HTTP 429 区分服务商限流、额度不足和原因不明，按 Retry-After 冷却（无该头时 60 秒），不自动重试；冷却期间关键词 / 日志查询仍可用。具体边界见[设置说明](settings-roadmap.md)。

实现和验证边界：[Console 问答说明](https://github.com/Nagi-226/RoboMind_Console/blob/master/docs/ai-status-chat.md)。
