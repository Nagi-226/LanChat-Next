# AI 状态问答

登录后在 **左下角齿轮 → 设置 → 板端连接 → AI 状态问答** 配置模型接口，启用后点击 **保存并连接**。API 密钥由当前 Windows 用户加密保存，界面留空表示保留已保存的密钥。

点击 **在聊天中询问板端状态** 打开专用板端账号的私聊。自然提问及追问例如：

- “现在板子各项状态怎么样？”
- “疲劳结果没算出来，可能是什么原因？”
- “现在可用内存多少？这能说明内存泄漏吗？”
- “链路是否稳定？哪些数据还不足以判断？”

配置群用 `/AI 问题`，普通群聊不触发。`/AI 清空` 清除当前会话的模型上下文；感知 / 链路 / 设备 / 帮助和 `/日志` 仍使用原确定性查询。

每次提问由后台 Console 获取三类新的板端状态快照，回答带采集时间。完整 AI 回答留在 PC 聊天；设备控制、语音和小智通用 AI 为后续。当前模型服务可能计费；全局最多 4 个任务，单会话最多 1 个，请等待回答后追问。

模型上下文最多三轮，仅保存在 Console 内存，10 分钟无活动过期。**聊天记录仍按 LanChat 保存**；清空上下文不会删除聊天历史。发送给模型的是问题、状态摘要和最近几轮对话，不包含图像、附件、完整串口日志或密钥。

断线、过期、未计算和未接入会明确提供给模型；AI 解释可用原关键词查询核对。接口不通时显示调用错误，普通聊天和确定性查询继续使用。

实现和验证边界：[Console 问答说明](https://github.com/Nagi-226/RoboMind_Console/blob/master/docs/ai-status-chat.md)。
