# 设置扩展计划与小智架构

决策记录：2026-11-23（Asia/Shanghai）。本页设置项为待办；当前已实现登录后服务器 / 板端连接、模型配置、板端页面和 USB 日志入口。

## 建议实施顺序

| 顺序 | 设置分组 | 必要选项与边界 |
|---|---|---|
| 1 | 账号与连接 | 当前账号 / 主机、退出登录、记住账号管理；连接检测、重连、LAN / Tailscale 指引。清除已记住的密码与删除聊天历史分别处理 |
| 2 | 通知与窗口 | 私聊 / 群 / 板端告警通知开关、提示音、免打扰、托盘与关闭行为、开机启动。消息主机托管状态要可见，防止关窗口后误以为主机仍运行 |
| 3 | 附件与存储 | 默认下载目录、缓存使用量与清理、自动下载限制；提示未完成的传输。共享主机附件额度只由主机管理者修改 |
| 4 | AI 与会话 | 接口检测、输出长度 / 超时、每天调用次数上限、使用统计、清空上下文。请求次数 / token 统计与提供方实际账单分开显示；确定性查询继续可用 |
| 5 | 显示与设备 | 字体大小 / 缩放、板端默认页面、重连偏好、日志级别 / 自动跟随 / 采集开关。USB 操作只作用于连接板子的主机 |
| 6 | 关于与诊断 | 客户端 / Console 版本、更新来源、复制脱敏连接诊断、导出必要日志；不导出密码或 API 密钥 |

设置页沿用左侧分类、右侧表单；保存连接配置、清理缓存、退出登录分别提供明确操作。首次安装仍保留登录页的地址输入。通知 / 托盘与 AI 限额需要实际实现和验收，不能将旧 Tauri 中同名功能视为 Qt 已完成。

## 小智是否是板子里的独立大模型

**不是。** 小智是开源设备固件和配套服务方案，提供语音交互、连接、屏幕和工具调用接口；自由对话能力通常来自服务端的大模型。

| 部分 | 一般职责 | 本项目当前状态 |
|---|---|---|
| ESP32-S3 | 麦克风 / 扬声器、离线唤醒、音频编码、联网、显示、设备工具 | RoboMind 五页终端、OV5640 感知与 VVOS 状态；未启用小智语音 |
| 小智配套服务 | 设备接入、ASR / TTS 或实时语音模型、会话与模型路由 | 待选型 / 接入；可使用托管服务或适配其他后端 |
| 对话大模型 | 理解问题、生成回答、按允许的接口使用工具 | 当前由 PC Console 调用配置的外部 API；不在 S3 运行 |

ESP-SR 离线唤醒可能使用板端小模型，它只识别唤醒词 / 有限语音指令，不能据此认为自由对话也离线运行。具体聊天模型取决于服务提供方和后端配置，不能仅凭“小智”名称确定是哪家模型。

上游 README 明确说明使用 Qwen / DeepSeek 等模型，提供 ESP-SR 离线唤醒、WebSocket 或 MQTT + UDP、Opus 音频与 ASR + LLM + TTS / 实时语音模型管线。参考：[xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)、[WebSocket 协议](https://github.com/78/xiaozhi-esp32/blob/main/docs/websocket.md)。

后续继续采用“板端提供真实状态和交互，PC / Console 管理模型与会话”的系列架构，优先共用现有文字问答。音频适配、服务激活、OV5640 差异和 MCP 工具需分别验收；控制工具另外定义权限和执行确认。
