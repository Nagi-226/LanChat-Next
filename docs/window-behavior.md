# Windows 窗口操作（2026-11-23）

## 按钮与拖动

- 最小化、最大化 / 还原、关闭按钮均为 **46 × 40** 逻辑像素，矢量图标画布均为 **12 × 12**；随 Windows 缩放比例绘制。
- 中间按钮随实际窗口状态切换：普通窗口为单方框，最大化为双窗口还原图标。关闭按钮有红色悬停反馈。
- 拖动顶部标题或空白处移动窗口，双击切换最大化 / 还原。服务器、板端连接和窗口按钮保留各自点击行为。
- Windows 的窗口吸附设置开启时，标题栏拖到顶部松开可最大化，拖到左右边缘可使用系统分屏；最大化后从标题栏拖动可还原并继续移动。
- 普通窗口的边缘与四角可缩放，最大化时关闭边缘缩放区域并让内容避开任务栏。

## 实现与验证范围

自绘标题栏保留暗色样式，Windows 接管移动、缩放和最大化 / 还原命令。最大化按钮提供 Windows 11 Snap 布局所需的原生命中区域；悬停布局面板的实际显示由系统支持和设置决定。

`window_controls` 检查图标画布、按钮尺寸、状态切换、最小化 / 关闭以及开发者工具栏。`window_controls_native` 使用真实 Windows 窗口检查标题 / 边缘 / 按钮命中、系统最大化与还原、任务栏工作区边界、按钮按下后拖出取消和原生标题栏双击。

本轮 Qt **14/14 通过**，包含上述两项、聊天单次回显、真实双客户端 LAN 和日志自动跟随回归。本机原生截图采用 150% 缩放；多屏混合缩放不在此次自动化检查范围内。

鼠标实机操作工具两次启动均报 `failed to write kernel assets: 系统找不到指定的路径。 (os error 3)`。因此自动化原生窗口检查不作为实际拖到屏幕边缘、从最大化拖回、Snap 悬停面板和多屏混合缩放的人工验收；这些手势仍待实机确认。本轮未更改 Windows 的吸附或其他系统设置。
